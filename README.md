# Claude Mods

Моды для Claude Code, которые помогают следить за лимитами, продолжать длинные задачи и распределять работу между сессиями.

Выбери нужные моды — весь комплект устанавливать необязательно. Работа проверена в Claude Desktop.

## Что есть в подборке

| Мод | Что даёт |
|---|---|
| **[CTX](#ctx)** | Контекст, лимиты и время до сброса рядом с чатом |
| **[Handoff](#handoff)** | Продолжение задачи после очистки чата по сохранённой сводке |
| **[Threads](#threads)** | Несколько сессий для параллельной работы над проектом |
| **[Session Hub](#session-hub)** | Все диалоги в одной панели с поиском и переключением |
| **[Delete Guard](#delete-guard)** | Подтверждение перед удалением файлов и другими опасными действиями |

## Как установить

### Прямо через чат

**1. Напиши Claude:**

> Установи в Claude Code моды ctx, handoff, threads, session-hub и delete-guard из GitHub-репозитория IT-Shelter-Labs/Claude-Mods. Проверь, что они включены.

Можно указать только один мод или несколько. Подтверди установку, если Claude попросит.

**2. После установки отправь:**

```text
/reload-plugins
```

Моды появятся в текущей сессии. Включать и отключать их можно через `/plugin`.

<details>
<summary>Установка из скачанного архива</summary>

На странице репозитория нажми **Code → Download ZIP** и распакуй архив в постоянную папку. Затем напиши Claude:

> Установи моды ctx, handoff, threads, session-hub и delete-guard из папки ПУТЬ_К_ПАПКЕ. Проверь, что они включены.

Вместо `ПУТЬ_К_ПАПКЕ` укажи расположение распакованного репозитория. После установки отправь `/reload-plugins`.

Оставь папку на месте, пока используешь её как источник плагинов.

</details>

<details>
<summary>Установка командами в чате</summary>

```text
/plugin marketplace add IT-Shelter-Labs/Claude-Mods
/plugin install ctx@claude-mods
```

Вместо `ctx` подставь нужное имя: `handoff`, `threads`, `session-hub` или `delete-guard`. Выбери область установки в открывшейся панели, затем выполни `/reload-plugins`.

</details>

## CTX

Показывает заполнение контекста, расход доступных лимитов за пять часов и неделю, время до их сброса. Значения видны рядом с чатом — не нужно каждый раз открывать отдельный индикатор.

| Команда | Действие |
|---|---|
| `/ctx` | Показать текущие значения |
| `/ctx hide` | Скрыть индикатор |
| `/ctx show` | Вернуть индикатор |

<details>
<summary>Дополнительный таймер кэша</summary>

`/ctx cache 5` или `/ctx cache 60` включает оценку времени кэша на 5 или 60 минут после успешного запроса модели. Это приблизительный отсчёт, а не проверка серверного кэша.

`/ctx cache off` отключает таймер. По умолчанию он выключен; после `/clear` отсчёт сбрасывается.

</details>

## Handoff

Помогает продолжить длинную задачу после очистки чата. Claude сохраняет цель, принятые решения и оставшиеся дела в документ, а затем продолжает по этой сводке. Не приходится заново объяснять проект.

По умолчанию мод предлагает передачу при 60% заполнения контекста. Очистка происходит после проверки документа; если запись прервана или передача отменена, чат остаётся.

| Команда | Действие |
|---|---|
| `/handoff-now` | Начать передачу |
| `/handoff-status` | Проверить состояние и найти документ |
| `/handoff-cancel` | Отменить передачу до очистки |
| `/handoff-resume` | Продолжить по готовому документу |
| `/handoff-threshold 70` | Предлагать передачу при 70% контекста |
| `/handoff-threshold off` | Выключить автоматическое предложение |

## Threads

Разделяет работу между отдельными сессиями Claude Code. У каждой своя задача и контекст; можно выбрать Sonnet или Opus, указать рабочую папку и вернуть результаты в основной чат.

Например, попроси Claude:

> Раздели проверку проекта на два потока. Первый ищет ошибки в API, второй проверяет интерфейс. Оба только читают файлы. Собери замечания в основной чат.

| Команда | Действие |
|---|---|
| `/threads` | Открыть панель потоков |
| `/threads cap 3` | Ограничить число активных потоков |

По умолчанию одновременно работают до трёх потоков. Лимит можно изменить от 1 до 8.

Потоки начинают с чтения файлов. Если нужны правки, прямо укажи это в задании. Для параллельного изменения кода подготовь отдельные рабочие копии проекта.

## Session Hub

Собирает диалоги Claude Desktop в одну панель. Видно, какие сессии работают, ждут ответа или завершены. Нужный чат можно найти по названию или проекту и сразу открыть.

| Команда | Действие |
|---|---|
| `/sessions` | Открыть или закрыть панель |
| `/sessions search сайт` | Найти диалоги по названию или проекту |
| `/sessions clear` | Сбросить поиск |
| `/sessions refresh` | Обновить список |

Если загрузка списка не удалась, панель сохраняет последний снимок и показывает, что он устарел.

## Delete Guard

Просит подтверждение для удаления файлов, сброса правок и некоторых других опасных команд. Показывает действие и указанные пути — ты выбираешь, разрешить его или отменить.

Мод начинает работать после загрузки, отдельная команда включения не нужна. Если подтверждение получить невозможно, распознанное опасное действие отклоняется.

Это дополнительная проверка команд, а не замена встроенных разрешений Claude Code.

## Настрой под себя

Моды можно менять обычным запросом к Claude. Открой репозиторий в Claude Code и объясни, что хочешь:

> В CTX оставь только контекст и недельный лимит. В Handoff измени порог по умолчанию на 70%. Сохрани остальные функции.

Claude поможет внести изменения и проверить результат.

<details>
<summary>Дополнительно — Autopilot Progress</summary>

В репозитории есть `autopilot-progress` для тех, кто использует совместимый внешний Autopilot — инструмент, который организует разработку по этапам и сохраняет состояние задач.

Мод показывает этапы, задачи, тесты и оценку оставшегося времени. Панель открывается командой `/autopilot-progress`.

Сам Autopilot в комплект не входит. Без него устанавливать этот мод не нужно.

</details>
